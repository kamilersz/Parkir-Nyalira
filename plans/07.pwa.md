# 07. PWA Configuration

## Overview

Make the app installable as a Progressive Web App for mobile users. Enable offline viewing of active tickets.

## Manifest

Create `public/manifest.json`:

```json
{
  "name": "Parkir Nyalira",
  "short_name": "Parkir",
  "description": "Self-service parking ticketing & payment",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#1d4ed8",
  "orientation": "portrait",
  "icons": [
    {
      "src": "/icons/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

### Layout Integration

In `src/app/layout.tsx`:

```html
<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#1d4ed8" />
```

## Service Worker

### Strategy: Network-first with cache fallback

For now, keep it simple:

1. **Always fetch from network first** for all pages and API calls
2. **Cache successful responses** for offline fallback
3. **Special handling for active tickets**: Cache `/tiket/[id]` pages when visited, so users can view their approval code offline

### Implementation Options

**Option A: next-pwa** (Recommended)

- Drop-in PWA support for Next.js
- Configured in `next.config.js`
- Handles service worker generation

**Option B: Manual service worker**

- More control but more maintenance
- Register in layout with `navigator.serviceWorker.register()`

### Offline Behavior

When offline:

- Show cached active tickets (approval code visible)
- Show "Anda sedang offline" banner
- New ticket creation blocked (requires network for payment)
- Cached location data available for viewing

## App Icons

Required icon sizes:

- `icon-192.png` — Standard PWA icon
- `icon-512.png` — High-res PWA icon
- `favicon.ico` — Browser tab icon
- `apple-touch-icon.png` — iOS home screen (180×180)

Placeholder icons can be generated with a simple logo (parking "P" symbol with blue background).

## Mobile UX Considerations

### Viewport & Touch

- `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">` — prevent zoom on form inputs
- Touch-friendly: large tap targets (min 44px)
- No horizontal scroll

### Input Optimization

- License plate input: `inputmode="text"` with `autocomplete="off"`
- Use `capitalize="characters"` for uppercase plate
- Numeric inputs: `inputmode="numeric"`

### QR Code Display

- QR code should be at least 256px on screen
- Centered and prominent
- High contrast (black on white)
- No decorative elements overlapping the QR

### Share/Screenshot

- "Bagikan tiket" button using Web Share API (`navigator.share()`)
- Fallback: screenshot hint text

## Future Enhancements
