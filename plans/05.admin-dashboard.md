# 05. Admin Dashboard

## Overview

Full admin dashboard for managing parking locations, pricing, vehicle rules, viewing transactions, and checking balances. Multiple admins can manage multiple locations.

## URL Structure

```
/admin                          → Dashboard overview (stats)
/admin/locations                → List all locations user can manage
/admin/locations/new            → Create new location
/admin/locations/[id]           → Location detail + settings
/admin/locations/[id]/pricing   → Manage pricing tiers
/admin/locations/[id]/vehicles  → Manage vehicle type detection rules
/admin/locations/[id]/transactions → Transaction list
/admin/locations/[id]/balance   → Balance & withdrawal history
/admin/team                     → Manage location admins
```

## Access Control

### Role-Based Permissions

| Action                 | OWNER | OPERATOR |
| ---------------------- | ----- | -------- |
| View dashboard         | ✓     | ✓        |
| View transactions      | ✓     | ✓        |
| Verify/check tickets   | ✓     | ✓        |
| Edit location settings | ✓     | ✗        |
| Manage pricing         | ✓     | ✗        |
| Manage vehicle rules   | ✓     | ✗        |
| Manage team/admins     | ✓     | ✗        |
| View balance details   | ✓     | ✗        |
| Withdraw balance       | ✓     | ✗        |

### Middleware

- All `/admin/*` routes require authentication
- Check if user has `LocationAdmin` record for any location
- For location-specific pages, verify user has access to that location
- API routes follow same permission checks

## Pages

### Dashboard Overview (`/admin`)

**Cards/Stats:**

- Total locations managed
- Today's transactions count & revenue
- Active tickets right now
- Total balance across all locations

**Quick links** to each managed location

### Location List (`/admin/locations`)

Table with columns:

- Name
- Slug
- Status (active/inactive)
- Pricing mode
- Today's revenue
- Current balance
- Actions (edit, view transactions)

### Create/Edit Location (`/admin/locations/new` and `[id]`)

**Form fields:**

- Name
- Slug (auto-generated from name, editable)
- Address
- Latitude / Longitude
- Description
- Pricing mode (FLAT_HOURLY or FIXED_DAILY)
- Active toggle

### Pricing Management (`/admin/locations/[id]/pricing`)

Table of pricing tiers per vehicle type:

- Vehicle type
- First hour rate
- Additional hour rate
- Daily rate
- Max daily rate
- Grace period (minutes)
- Active toggle
- Edit button

**Add tier form**: select vehicle type + fill rates

### Vehicle Type Rules (`/admin/locations/[id]/vehicles`)

Table of regex-based detection rules:

- Name (e.g., "Motor standar")
- Vehicle type
- Pattern (regex)
- Priority
- Active toggle
- Test input (try a plate number to see which rule matches)

**Add rule form**:

- Name
- Vehicle type dropdown
- Regex pattern input with syntax validation
- Priority number
- Preset patterns available as quick-fill:
  - Motorcycle: `^[A-Z]{1,2}\d{1,4}[A-Z]{0,2}$`
  - Car: `^[A-Z]{1,2}\d{1,4}[A-Z]{3}$`
  - Bus/Truck: custom

### Transaction List (`/admin/locations/[id]/transactions`)

**Filters:**

- Date range
- Status (all, pending, paid, expired, cancelled)
- Vehicle type
- License plate search

**Table columns:**

- Ticket ID
- License plate
- Vehicle type
- Duration
- Amount
- Status badge
- Payment method
- Created at
- Paid at

**Export**: CSV download of filtered transactions

### Balance Page (`/admin/locations/[id]/balance`)

**Summary:**

- Current balance
- Today's income
- This week's income
- This month's income

**Balance history chart**: daily income over last 30 days

**Withdrawal log** (if implemented in future):

- Date
- Amount
- Status
- Notes

### Team Management (`/admin/team`)

**Per-location admin list:**

- User name + email
- Role (OWNER / OPERATOR)
- Added date
- Remove button (only for OWNERS)

**Invite admin form:**

- Email input
- Role selection
- Send invite (for now: directly add if user exists)

## API Endpoints

| Endpoint                                      | Method | Purpose                                  |
| --------------------------------------------- | ------ | ---------------------------------------- |
| `/api/admin/locations`                        | GET    | List managed locations                   |
| `/api/admin/locations`                        | POST   | Create location                          |
| `/api/admin/locations/[id]`                   | GET    | Location detail                          |
| `/api/admin/locations/[id]`                   | PATCH  | Update location settings                 |
| `/api/admin/locations/[id]/pricing`           | GET    | List pricing tiers                       |
| `/api/admin/locations/[id]/pricing`           | POST   | Create pricing tier                      |
| `/api/admin/locations/[id]/pricing/[tierId]`  | PATCH  | Update tier                              |
| `/api/admin/locations/[id]/pricing/[tierId]`  | DELETE | Remove tier                              |
| `/api/admin/locations/[id]/vehicles`          | GET    | List vehicle type rules                  |
| `/api/admin/locations/[id]/vehicles`          | POST   | Create rule                              |
| `/api/admin/locations/[id]/vehicles/[ruleId]` | PATCH  | Update rule                              |
| `/api/admin/locations/[id]/vehicles/[ruleId]` | DELETE | Remove rule                              |
| `/api/admin/locations/[id]/transactions`      | GET    | Transaction list (paginated, filterable) |
| `/api/admin/locations/[id]/balance`           | GET    | Balance summary + history                |
| `/api/admin/locations/[id]/team`              | GET    | List admins                              |
| `/api/admin/locations/[id]/team`              | POST   | Add admin                                |
| `/api/admin/locations/[id]/team/[adminId]`    | PATCH  | Update role                              |
| `/api/admin/locations/[id]/team/[adminId]`    | DELETE | Remove admin                             |
| `/api/admin/stats`                            | GET    | Dashboard overview stats                 |
