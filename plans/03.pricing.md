# 03. Pricing Engine

## Overview

Calculates parking fees based on location settings, vehicle type, and duration.

## Pricing Modes

### FLAT_HOURLY Mode

Charged per hour block. First hour has a different rate than additional hours.

```
totalPrice = firstHourRate + (additionalHours × additionalHourRate)
```

**Rules:**

- Duration ≤ 60 min → charged `firstHourRate`
- Duration > 60 min → `firstHourRate` + ceil((duration - 60) / 60) × `additionalHourRate`
- Optional `maxDailyRate` caps the total (if set)
- Grace period: first N minutes free (informational — does not affect calculation)

**Example:**

- Car, 2.5 hours, firstHourRate=10000, additionalHourRate=5000
- First hour: Rp 10.000
- Remaining 1.5 hours → ceil(1.5) = 2 additional hours: 2 × 5.000 = Rp 10.000
- Total: Rp 20.000

### FIXED_DAILY Mode

Flat rate regardless of duration. The user selects "1 day" as the only duration option.

```
totalPrice = dailyRate
```

**Rules:**

- Duration is always 24 hours (or location-defined "day" period)
- No hourly calculation
- Simpler UX: only "1 hari" button shown

## Price Calculation Function

Located at `src/lib/pricing.ts`:

```typescript
interface PriceInput {
  pricingMode: PricingMode;
  firstHourRate: number;
  additionalHourRate: number;
  dailyRate: number;
  maxDailyRate: number | null;
  durationMinutes: number;
}

interface PriceBreakdown {
  firstHour: number;
  additionalHours: number;
  additionalHourCount: number;
  dailyRate: number;
  total: number;
  capped: boolean;
  capAmount: number | null;
}

function calculatePrice(input: PriceInput): PriceBreakdown;
```

## PricingTier Selection

Given a location and vehicle type, select the matching `PricingTier`:

1. Look up tier by `(locationId, vehicleType)` where `isActive = true`
2. If no tier found → error: vehicle type not supported at this location
3. Use the tier's rates for calculation

## API Endpoint

`GET /api/locations/[slug]/pricing?vehicleType=CAR&duration=120`

Returns:

```json
{
  "pricingMode": "FLAT_HOURLY",
  "breakdown": {
    "firstHour": 10000,
    "additionalHourCount": 1,
    "additionalHours": 5000,
    "total": 15000,
    "capped": false,
    "capAmount": null
  },
  "formatted": {
    "firstHour": "Rp 10.000",
    "additionalHours": "Rp 5.000",
    "total": "Rp 15.000"
  }
}
```

## Currency Formatting

All amounts displayed as `Rp X.XXX` format (Indonesian style):

- `15000` → `Rp 15.000`
- `100000` → `Rp 100.000`

Helper function in `src/lib/pricing.ts`:

```typescript
function formatRupiah(amount: number): string;
```
