# 01. Database Schema Design

## Overview

Multi-location parking system with per-location pricing, vehicle type detection rules, ticketing, and payment tracking.

## Models

### ParkingLocation

Central entity for each parking facility.

| Field       | Type                          | Notes                                  |
| ----------- | ----------------------------- | -------------------------------------- |
| id          | String (@id @default(cuid())) |                                        |
| name        | String                        | Display name (e.g., "Parkir Mall XYZ") |
| slug        | String (@unique)              | URL-friendly identifier                |
| address     | String?                       | Full address                           |
| latitude    | Float?                        |                                        |
| longitude   | Float?                        |                                        |
| description | String?                       |                                        |
| pricingMode | PricingMode enum              | `FLAT_HOURLY` or `FIXED_DAILY`         |
| balance     | Int (@default(0))             | Accumulated revenue in Rp              |
| isActive    | Boolean (@default(true))      | Soft-disable location                  |
| createdAt   | DateTime                      |                                        |
| updatedAt   | DateTime                      |                                        |

Relations: `admins`, `pricingTiers`, `vehicleTypeRules`, `tickets`

### PricingMode Enum

```
enum PricingMode {
  FLAT_HOURLY    // charged per hour (first hour rate + additional hour rate)
  FIXED_DAILY    // flat rate for the whole day regardless of duration
}
```

### LocationAdmin

Join table for many-to-many User ↔ ParkingLocation.

| Field      | Type                          | Notes                 |
| ---------- | ----------------------------- | --------------------- |
| id         | String (@id @default(cuid())) |                       |
| userId     | String                        | FK → User             |
| locationId | String                        | FK → ParkingLocation  |
| role       | AdminRole enum                | `OWNER` or `OPERATOR` |
| createdAt  | DateTime                      |                       |

**Unique constraint**: `(userId, locationId)`

### AdminRole Enum

```
enum AdminRole {
  OWNER      // full control: settings, pricing, admins, withdraw
  OPERATOR   // view transactions, verify tickets
}
```

### VehicleType Enum

```
enum VehicleType {
  MOTORCYCLE
  CAR
  BUS
  TRUCK
}
```

### VehicleTypeRule

Regex-based auto-detection of vehicle type from license plate format. Loaded per-location from DB.

| Field       | Type                          | Notes                                                                   |
| ----------- | ----------------------------- | ----------------------------------------------------------------------- |
| id          | String (@id @default(cuid())) |                                                                         |
| locationId  | String                        | FK → ParkingLocation                                                    |
| vehicleType | VehicleType                   |                                                                         |
| name        | String                        | Rule description (e.g., "Motor plates end with no letter")              |
| pattern     | String                        | Regex pattern applied to normalized plate (e.g., `^\d{1,4}[A-Z]{0,2}$`) |
| priority    | Int (@default(0))             | Higher priority checked first                                           |
| isActive    | Boolean (@default(true))      |                                                                         |

Example rules:

- Motorcycle: plate ends with 1-4 digits + 0-2 letters (e.g., `B 1234 AB`) — shorter patterns
- Car: plate ends with 1-4 digits + 3 letters (e.g., `B 1234 ABC`) — has 3 trailing letters
- Bus: starts with specific area codes + specific format

### PricingTier

Per-location, per-vehicle-type pricing configuration.

| Field              | Type                          | Notes                               |
| ------------------ | ----------------------------- | ----------------------------------- |
| id                 | String (@id @default(cuid())) |                                     |
| locationId         | String                        | FK → ParkingLocation                |
| vehicleType        | VehicleType                   |                                     |
| firstHourRate      | Int                           | Price for first hour in Rp          |
| additionalHourRate | Int                           | Price per additional hour in Rp     |
| dailyRate          | Int                           | Fixed daily rate in Rp              |
| maxDailyRate       | Int                           | Cap for hourly mode (optional)      |
| gracePeriodMinutes | Int (@default(15))            | Free minutes before charging starts |
| isActive           | Boolean (@default(true))      |                                     |

**Unique constraint**: `(locationId, vehicleType)`

### TicketStatus Enum

```
enum TicketStatus {
  PENDING     // created, awaiting payment
  PAID        // payment confirmed, approval code generated
  EXPIRED     // payment timeout or ticket duration exceeded
  CANCELLED   // manually cancelled
}
```

### ParkingTicket

The core ticket entity.

| Field           | Type                             | Notes                                            |
| --------------- | -------------------------------- | ------------------------------------------------ |
| id              | String (@id @default(cuid()))    |                                                  |
| locationId      | String                           | FK → ParkingLocation                             |
| userId          | String?                          | FK → User (nullable — anonymous tickets allowed) |
| licensePlate    | String                           | Normalized uppercase plate (e.g., `B1234ABC`)    |
| licensePlateRaw | String                           | Original input (e.g., `B 1234 ABC`)              |
| vehicleType     | VehicleType                      |                                                  |
| durationMinutes | Int                              | Requested parking duration                       |
| totalPrice      | Int                              | Calculated price in Rp                           |
| status          | TicketStatus (@default(PENDING)) |                                                  |
| approvalCode    | String?                          | 4-digit code shown on paid ticket                |
| timeoutCode     | String?                          | 4-digit code derived from expiry time            |
| validFrom       | DateTime?                        | When the ticket becomes valid (payment time)     |
| validUntil      | DateTime?                        | validFrom + durationMinutes                      |
| paidAt          | DateTime?                        |                                                  |
| createdAt       | DateTime                         |                                                  |
| updatedAt       | DateTime                         |                                                  |

Relations: `location`, `user`, `payment`

Indexes: `(licensePlate)`, `(status)`, `(locationId, createdAt)`

### Payment

Payment record linked to a ticket.

| Field            | Type                          | Notes                                |
| ---------------- | ----------------------------- | ------------------------------------ |
| id               | String (@id @default(cuid())) |                                      |
| ticketId         | String (@unique)              | FK → ParkingTicket (1:1)             |
| amount           | Int                           | Amount in Rp                         |
| qrisPayload      | String?                       | QRIS string used to generate QR code |
| qrisExpiry       | DateTime?                     | When the QRIS code expires           |
| status           | PaymentStatus                 |                                      |
| webhookPayload   | String?                       | Raw webhook JSON for audit           |
| webhookSignature | String?                       |                                      |
| paidAt           | DateTime?                     |                                      |
| createdAt        | DateTime                      |                                      |
| updatedAt        | DateTime                      |                                      |

### PaymentStatus Enum

```
enum PaymentStatus {
  PENDING
  SUCCESS
  FAILED
  EXPIRED
  REFUNDED
}
```

### LicensePlateHistory

Users can save frequently used plates for quick selection.

| Field           | Type                          | Notes                                  |
| --------------- | ----------------------------- | -------------------------------------- |
| id              | String (@id @default(cuid())) |                                        |
| userId          | String                        | FK → User                              |
| licensePlate    | String                        | Normalized uppercase                   |
| licensePlateRaw | String                        | Display format                         |
| vehicleType     | VehicleType                   | Last used vehicle type for this plate  |
| label           | String?                       | User-given label (e.g., "Motor utama") |
| useCount        | Int (@default(1))             |                                        |
| lastUsedAt      | DateTime                      |                                        |
| createdAt       | DateTime                      |                                        |

**Unique constraint**: `(userId, licensePlate)`

## Entity Relationships

```
User ───< LicensePlateHistory
User ───< LocationAdmin >─── ParkingLocation
User ───< ParkingTicket (nullable)

ParkingLocation ───< PricingTier
ParkingLocation ───< VehicleTypeRule
ParkingLocation ───< ParkingTicket
ParkingLocation ───< LocationAdmin

ParkingTicket ──── Payment (1:1)
```

## Migration Notes

- Keep existing `User`, `Session`, `Account`, `Verification` models from Better Auth untouched
- All monetary values as `Int` (Rp, no decimals)
- Normalize license plates: uppercase, strip spaces for storage; keep raw for display
